# Группа компаний «Союз»

Отдельный сайт на основе https://soyuz05.ru/. Мобильное верхнее меню и нижняя панель из пяти действий, предоставленное пользователем видео на первом экране с затемнением.

## Запуск

Node.js 22+: `npm run dev` (порт 4196), `npm run check`, `npm run build`. Статическая сборка — `dist/`. Vercel подключён к ветке main репозитория Standartrealty/soyuz-group.

## Состав

Компания, восемь проектов с галереями, 112 вариантов планировок, подбор квартиры, условия покупки, фотографии жилой среды, услуги покупателям/инвесторам/риелторам, девять сканов документов, новости и ссылки на фото/видеоотчёты, консультация, отзывы Яндекс, FAQ и контакты.

85 карточек имеют схемы. Для 27 карточек без изображения либо с противоречивой привязкой исходной схемы показано «Схема уточняется». Весь оригинальный контент сохранён в локальном архиве. Наличие, цены и сроки не выдумывались.

Формы демонстрационные: введённые данные не отправляются и не сохраняются. Для реального обращения доступны официальные телефон, WhatsApp и почта. Видео является пользовательской видеоиллюстрацией, а не подтверждённой съёмкой объекта компании. Водяные знаки сохранены.

## Архив

Локальный `source-content/`: 25 уникальных HTML-страниц и их текстовые снимки, robots.txt, 740 сохранённых медиаресурсов (в том числе варианты размеров). `catalog.json` фиксирует URL, соответствие файлам и ошибки. В сборку включены оптимизированные изображения; полный архив оригиналов остаётся в рабочей папке пользователя.

Сохранены документы, фотоотчёты, проектные страницы, новости, контакты и страница отзывов. Внешние видеосервисы сохранены как ссылки; не все внешние видео скачаны. Недоступные ссылки отражены в каталоге. Подробности и расхождения — в `VERIFICATION.md` и `source-content/plan-discrepancies.json`.
